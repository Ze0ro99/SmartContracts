# Development Command Reference

This file is the concise command index for contributors. See [Local Development Environment](LOCAL_DEVELOPMENT_ENVIRONMENT.md) for setup and safety boundaries.

```sh
make bootstrap
make fixture
make fmt
make check
make test
make wasm
```

CI is authoritative for shared review status. Record workflow URLs and exact commit SHAs in release evidence; never infer a pass from a queued or missing run.
